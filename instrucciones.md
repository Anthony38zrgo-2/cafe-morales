# Instrucciones para agente — Mejora visual de Morales Coffee Market

Mejora la integración visual de la web de Morales Coffee Market sin cambiar su identidad actual.

## Objetivo

Mantener el estilo clay, la paleta existente, las tipografías actuales y la estructura data-driven, pero hacer que la página se sienta más cohesionada entre secciones, menos fragmentada y con una dirección artística más consistente.

## Lineamientos

- Conserva el preset clay, colores, tipografías y lenguaje visual actual.
- No rediseñes la marca ni conviertas la web a otro estilo.
- Explora primero la arquitectura, componentes, estilos y sistema de configuración existente.
- Haz re-planning durante el trabajo según lo que encuentres.
- Prioriza integración entre secciones antes que añadir nuevos componentes aislados.
- Introduce recursos SVG vectoriales propios para conectar visualmente las secciones: ondas, formas orgánicas, vapor, granos, ramas de café u otros motivos compatibles con la identidad.
- Reutiliza motivos gráficos a lo largo de la página para crear continuidad visual.
- Mejora el uso jerárquico de las tipografías existentes sin reemplazarlas.
- Revisa espaciados, transiciones entre bloques, solapamientos ligeros y composición general.
- Mejora las animaciones existentes y añade microanimaciones suaves donde aporten valor.
- Usa movimiento lento y discreto para elementos decorativos como granos, SVGs, imágenes o formas de fondo.
- Mejora el comportamiento hover y las transiciones de cards y CTA sin volver la interfaz excesivamente animada.
- Integra mejor las imágenes y assets actuales dentro de cada composición.
- Evita saturar la página con decoración; cada recurso visual debe tener una función compositiva.
- Mantén accesibilidad, responsive design y `prefers-reduced-motion`.
- Evita dependencias nuevas salvo que exista una justificación clara.
- Mantén la arquitectura data-driven y reutilizable existente.
- No rompas el catálogo, pedidos, WhatsApp, navegación ni configuración actual.

## Continuidad visual prioritaria

Presta especial atención a la continuidad:

**Hero → Catálogo → Ritual → Origen/Selección → Contacto**

La página final debe sentirse como una sola composición continua en estilo clay, no como una sucesión de secciones independientes.

## Forma de trabajo

Trabaja de forma iterativa:

1. Inspecciona.
2. Identifica los cambios de mayor impacto.
3. Implementa.
4. Revisa visualmente.
5. Reajusta el plan si es necesario.

No intentes implementar todas las ideas posibles. Prioriza aquellas que produzcan el mayor incremento de cohesión visual con la menor complejidad innecesaria.
